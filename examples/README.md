# KeyStar Examples (実例・サンプルコード置き場)

本ディレクトリは、`KeyStar` のコアロジック（電卓、補完検索、ショートカット走査、トレイアイコン生成等）を、GUI ウィンドウを立ち上げずに単体で試せる **最小実行可能サンプルコード（Examples）** の配置場所です。

---

## 📌 サンプルコード一覧

| サンプル名 (ファイル名) | 対象モジュール  | 目的・内容                                                     |
| :---------------------- | :-------------- | :------------------------------------------------------------- |
| `calc_cli.rs`           | `src/calc.rs`   | CLI 上で四則演算式を入力し、リアルタイム評価とカンマ整形を確認 |
| `search_cli.rs`         | `src/search.rs` | コンソール上でクエリを与え、前方・部分一致のスコアリングを確認 |
| `icon_gen.rs`           | `src/tray.rs`   | 内蔵プロシージャル 32x32 RGBA アイコンを生成してサイズを確認   |

---

## 🚀 実行コマンド

```powershell
# 特定の example を実行するコマンド例
cargo run --example calc_cli

# リリースビルドで実行
cargo run --release --example search_cli
```
