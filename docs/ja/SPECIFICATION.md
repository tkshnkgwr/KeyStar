# Re:CraftLaunch 基本仕様書 (Specification)

## 1. アプリケーション概要

| 項目         | 内容                                                                       |
| :----------- | :------------------------------------------------------------------------- |
| **アプリ名** | Re:CraftLaunch                                                             |
| **種別**     | Windowsデスクトップ向け 超軽量1行キーボードランチャー                      |
| **開発言語** | Rust (Edition 2024)                                                        |
| **GUI基盤**  | `eframe` / `egui`                                                          |
| **対象OS**   | Windows 11 (x86_64)                                                        |

## 2. コア機能要件

### 2.1 ショートカット・ファイル名補完起動（機能①）
1. **ショートカット監視ディレクトリ**:
   - 監視対象: `%USERPROFILE%\commands`（環境変数展開）およびアプリ同梱の `shortcuts/` ディレクトリ。
   - 対象拡張子: `.lnk`, `.url`, `.bat`, `.cmd`, `.exe`, `.ps1` 等。
2. **インデックス生成とキャッシュ**:
   - 起動時に対象フォルダ内のファイル一覧を読み込み、ファイル名（拡張子除く）と実体パスのマッピングをメモリ内に保持。
   - フォルダ変更検知（または定期的・ホットキー呼出時の軽量タイムスタンプ確認）による動的更新。
3. **インクリメンタルフィルタリング**:
   - ユーザー入力文字列（大文字・小文字不問）に対し、前方一致および部分一致で候補を絞り込み。
   - 上位候補を最大 5〜10 件、入力枠の下部にドロップダウンリスト形式で表示。
4. **実行・起動**:
   - `Enter` キー押下で選択されたアイテムを `open::that_detached(path)` 等により非同期キック。
   - キックと同時にランチャーのウィンドウを即座に非表示（非アクティブ化）。

### 2.2 入力欄での即時四則演算（電卓機能）（機能②）
1. **数式パースとリアルタイム評価**:
   - 入力文字列に数値および四則演算子（`+`, `-`, `*`, `/`, `%`, `(`, `)`）が含まれている場合、`evalexpr` を用いてバックグラウンドで即時パース。
   - 有効な計算結果が得られた場合、候補リストの最上段に `= <計算結果>` としてリアルタイム表示。
2. **計算結果のクリップボード格納**:
   - 数式入力状態で `Enter` を押した場合、計算結果の数値を OS クリップボードにコピーし、ウィンドウを即座に非表示化。

## 3. UI / UX 仕様

### 3.1 ウィンドウデザイン
- **サイズ**: 幅 450〜550px、高さ（入力欄のみの場合）約 36〜44px。
- **配置**: プライマリモニタの画面中央、または画面上部（CraftLaunch標準スタイル）。
- **装飾**:
  - タイトルバーなし（Borderless / Frameless）。
  - タスクバーに表示しない（システムトレイ常駐）。
  - 常に最前面表示（Always on Top）。

### 3.2 キーボード操作体系

| キー操作            | 動作                                                    |
| :------------------ | :------------------------------------------------------ |
| `Alt + Space`       | ランチャーの表示 / 非表示トグル（グローバルホットキー） |
| `Enter`             | 選択候補の実行、または計算結果をコピーして閉じる        |
| `Esc`               | 何もせずウィンドウを非表示にする                        |
| `Tab` / `Shift+Tab` | 候補リストの次 / 前の項目を選択                         |
| `Ctrl+n` / `Ctrl+p` | Vim風の次 / 前の候補選択                                |
| `Down` / `Up`       | 矢印キーによる次 / 前の候補選択                         |

## 4. アーキテクチャ設計

```mermaid
flowchart TD
    subgraph OS ["Windows OS"]
        HotKey["グローバルホットキー (Alt+Space)"]
        FS["ショートカットフォルダ (%USERPROFILE%\\commands)"]
        Clip["OS クリップボード"]
        Shell["open::that (アプリ起動)"]
    end

    subgraph App ["Re:CraftLaunch"]
        Tray["システムトレイ常駐 (tray-icon)"]
        Window["egui/eframe 1行ウィンドウ"]
        
        subgraph Logic ["内部ロジック"]
            Index["ショートカットインデクサ (メモリキャッシュ)"]
            Calc["数式評価器 (evalexpr)"]
            Filter["インクリメンタル検索エンジン"]
        end
    end

    HotKey -->|呼出シグナル| Window
    Tray -->|メニュー/終了| App
    FS -->|起動時/定期読込| Index
    
    Window -->|入力文字列| Filter
    Window -->|入力文字列| Calc
    Index -->|キャッシュデータ| Filter
    
    Filter -->|候補リスト| Window
    Calc -->|計算結果| Window
    
    Window -->|Enter (アプリ)| Shell
    Window -->|Enter (計算)| Clip
```
