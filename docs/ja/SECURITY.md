# KeyStar: セキュリティポリシー (SECURITY)

本ドキュメントは、`KeyStar` におけるセキュリティ方針、設計上の権限境界、および脆弱性報告手順を規定します。

---

## 1. セキュリティ設計原則 & 境界

### 1.1 プロセス実行権限とショートカットキック
- `KeyStar` は、一般ユーザー権限（非管理者権限）で動作することを前提として設計されています。
- ショートカットやスクリプトの起動には `open::that_detached` を使用し、Windowsの標準シェル関連付け（ShellExecuteEx相当）に従ってプロセスを分離起動します。
- 不明な外部URLや不正なコマンドを自動実行することは一切行わず、ユーザーが明示的に登録したフォルダ内のファイル、または明示的にキー入力して `Enter` を押したアイテムのみを起動対象とします。

### 1.2 数式評価エンジン (`evalexpr`) の安全性
- 電卓機能に用いている `evalexpr` は、安全なメモリ空間内で純粋な算術式をパース・評価します。
- OSのシェルコマンド実行（`system()` や `exec()` 等）やファイルシステムアクセス、ネットワーク通信を行う機能は含まれておらず、任意のコード実行リスクはありません。
- ゼロ除算や数値オーバーフロー等の異常入力に対してもパニックを起こさず、安全に `None` を返す防御的実装を行っています。

---

## 2. 監視フォルダの保護に関する推奨事項

- ショートカット監視フォルダ（`%USERPROFILE%\commands`）には、信頼できるアプリケーションやバッチファイルのみを配置してください。
- 共有PCやマルチユーザー環境において、当該フォルダに他ユーザーからの書き込み権限が付与されていないことをご確認ください。

---

## 3. 脆弱性の報告窓口

本ソフトウェアにおいてセキュリティ上の脆弱性や懸念を発見された場合は、公開のIssueを作成せず、リポジトリ管理者宛てに個別にご連絡いただくようお願いいたします。
迅速に調査およびパッチ対応を実施いたします。
