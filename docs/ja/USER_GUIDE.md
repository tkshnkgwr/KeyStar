# KeyStar: ユーザーガイド (USER_GUIDE)

名作キーボードランチャー「CraftLaunch 2」の原点思想を受け継ぐ、超軽量1行キーボードランチャー『KeyStar』の操作・設定マニュアルです。

---

## 1. クイックスタート

### ステップ 1: 起動
- `KeyStar.exe` を起動します。
- 初回起動時、タスクバーではなく**システムトレイ**に常駐し、自動的にショートカット監視フォルダが作成されます。

### ステップ 2: 呼び出し
- キーボードの **`Alt + Space`** を押すと、画面上部（または中央）に1行の入力枠がポップアップします。

### ステップ 3: 終了
- システムトレイのアイコンを右クリックし、「終了」を選択します。

---

## 2. ショートカット登録方法（ショートカット置き場方式）

KeyStar には面倒な設定画面や複雑な設定ファイルはありません。
**「決めたフォルダにショートカットを置くだけ」** で登録が完了します。

### 監視フォルダの場所
- **標準フォルダ**: `%USERPROFILE%\commands`  
  （例: `C:\Users\<ユーザー名>\commands`）
- **ポータブルフォルダ**: アプリ本体と同じ場所にある `shortcuts\` フォルダ

### 登録手順
1. エクスプローラーで `%USERPROFILE%\commands` を開きます。
2. 起動したいアプリ、ツール、フォルダ、Webサイトのショートカット（`.lnk` / `.url` / `.bat` / `.cmd` / `.exe` / `.ps1`）を放り込みます。
3. これだけで即座に補完候補として認識されます（アプリの再起動不要）。

> 💡 **便利な使い方**:
> ショートカットの名前を `c.lnk`（Chrome）や `n.lnk`（Notepad）など短い名前にリネームしておくと、1〜2文字タイプして `Enter` を押すだけで爆速起動できます。

## 3. 電卓機能の使い方

入力枠に計算式をそのまま入力すると、即座に計算結果が候補の最上段に現れます。

| 入力例            | 表示結果  | `Enter` 押下時の動作                       |
| :---------------- | :-------- | :----------------------------------------- |
| `1280 * 1.1`      | `= 1,408` | クリップボードに `1408` をコピーして閉じる |
| `10 / 4`          | `= 2.5`   | クリップボードに `2.5` をコピーして閉じる  |
| `(100 + 200) * 3` | `= 900`   | クリップボードに `900` をコピーして閉じる  |
| `10 % 3`          | `= 1`     | クリップボードに `1` をコピーして閉じる    |

## 4. キーボード操作一覧

| キー操作          | 動作                                                    |
| :---------------- | :------------------------------------------------------ |
| **`Alt + Space`** | ランチャーの表示 / 非表示トグル（グローバルホットキー） |
| **`Enter`**       | 選択中アイテムの起動、または計算結果をコピーして閉じる  |
| **`Esc`**         | 何も実行せずにランチャーを閉じる                        |
| **`Tab`**         | 次の候補を選択                                          |
| **`Shift + Tab`** | 前の候補を選択                                          |
| **`Ctrl + n`**    | 次の候補を選択（Vim風移動）                             |
| **`Ctrl + p`**    | 前の候補を選択（Vim風移動）                             |
| **`Down` / `Up`** | 矢印キーによる候補選択                                  |

## 5. 引数付き起動（コマンド実行）

ショートカット名やスクリプト名の後ろに半角スペースを空けて引数を入力すると、起動先のプログラムに引数を渡して実行できます。

| 入力例                      | 動作                                                              |
| :-------------------------- | :---------------------------------------------------------------- |
| `cmd /k ipconfig`           | コマンドプロンプトを起動し、引数 `/k ipconfig` を渡して即座に実行 |
| `code .`                    | VS Code を起動し、カレントディレクトリを開く                      |
| `chrome https://github.com` | Google Chrome で指定 URL を直接開く                               |

> 💡 **ポイント**:
> 引数を入力中も、先頭のコマンド単語（例: `cmd` や `code`）に基づいて候補リストが絞り込まれた状態が維持されます。

---

## 6. スラッシュコマンド（ビルトイン機能）

入力欄に **`/`** を入力すると、KeyStar 自体の制御や Windows システム操作、生産性ユーティリティを即座に実行できます（インクリメンタル補完対応）。

| コマンド                   | 機能                     | 実行内容                                                                 |
| :------------------------- | :----------------------- | :----------------------------------------------------------------------- |
| **`/task`**                | タスクマネージャー起動   | Windows 標準の `taskmgr.exe` を非同期起動                                |
| **`/config`**              | 設定フォルダを開く       | ショートカット監視フォルダ（設定場所）をエクスプローラーで開く           |
| **`/cmd`**                 | コマンドフォルダを開く   | コマンド置き場（`%USERPROFILE%\commands`）を開く                         |
| **`/reload`**              | ショートカット再読み込み | フォルダ内の変更を即座に再スキャンしてキャッシュを更新                   |
| **`/restart`**             | KeyStar 再起動           | KeyStar プロセスを一度終了し、自動で新しく再起動                         |
| **`/date`** / **`/today`** | 今日の日付コピー         | `YYYY-MM-DD` 形式（例: `2026-10-21`）をクリップボードにコピー            |
| **`/time`**                | 現在時刻コピー           | `HH:MM:SS` 形式（例: `17:30:00`）をクリップボードにコピー                |
| **`/ip`**                  | ローカルIPコピー         | 端末の主要ローカルIPアドレス（`192.168.x.x` 等）をクリップボードにコピー |
| **`/lock`**                | 画面ロック               | Windows 画面を即座にロック（`Win + L` 相当）                             |
| **`/sleep`**               | PCスリープ               | Windows をスリープ状態に移行                                             |
| **`/shutdown`**            | PCシャットダウン         | Windows を即座に電源OFF（シャットダウン）                                |
| **`/help`**                | コマンド一覧             | 利用可能な全スラッシュコマンドを候補リストに展開                         |
| **`/exit`**                | KeyStar 終了             | KeyStar を完全に終了                                                     |
