# Re:CraftLaunch: テスト設計 & 品質方針 (TESTING)

本ドキュメントは、`Re:CraftLaunch` におけるテストアーキテクチャ、テスト分離規約、および品質検証手順を規定します。

---

## 1. テストアーキテクチャ（3層分離構造）

```
                    ┌─────────────────────────────────────────┐
                    │            Rust テスト体系              │
                    └────────────────────┬────────────────────┘
                                         │
       ┌─────────────────────────────────┼─────────────────────────────────┐
       ▼                                 ▼                                 ▼
【内部単体テスト】               【公開API統合テスト】             【ドキュメンテーションテスト】
・配置: src/*.rs 内              ・配置: tests/*.rs                ・配置: /// # Examples
・視点: ホワイトボックス         ・視点: ブラックボックス (外部)   ・視点: ドキュメント動作検証
・対象: 非公開関数・エッジケース ・対象: クレート公開API (pub)     ・対象: 代表的利用例
```

| テスト層               | 配置場所                      | 主な検証目的                                               | コマンド                           |
| :--------------------- | :---------------------------- | :--------------------------------------------------------- | :--------------------------------- |
| **内部単体テスト**     | `src/*.rs` (`mod tests`)      | 非公開パース関数、3桁カンマ区切り、エッジケースのピンポイント検証 | `cargo test --lib`                 |
| **公開API統合テスト**  | `tests/*.rs`                  | クレート外部視点でのシナリオテスト、複合条件での振る舞い検証 | `cargo test --test <name>`         |
| **Docテスト**          | `src/*.rs` (`/// # Examples`) | ドキュメント内のコード例が常に最新コードで動作することの担保 | `cargo test --doc`                 |

---

## 2. テストスイート構成

### 2.1 電卓テスト (`src/calc.rs` & `tests/calc_integration.rs`)
- **単体テスト**:
  - `is_evaluable`: 演算子判定、単一数値の除外、空白文字列。
  - `format_integer_with_commas`: 負の数、極大数値、0の桁区切り。
  - `promote_integers_to_floats`: 実数除算のための安全なトークン変換。
- **統合テスト**:
  - 四則演算（加減乗除、剰余）。
  - 実数除算（`10 / 4 = 2.5`）の自動判定。
  - ゼロ除算時の安全な `None` 返却（非パニック保証）。

### 2.2 インデクサテスト (`src/indexer.rs` & `tests/indexer_integration.rs`)
- **単体テスト**:
  - `ShortcutItem::from_path`: 拡張子判定（`.lnk`, `.url`, `.bat` 等）、対象外拡張子の除外。
  - `scan`: 重複ファイルの除外、大文字小文字無視ソート。
  - `needs_rescan`: フォルダ未変更時の再走査スキップ判定。
- **統合テスト**:
  - 一時ディレクトリを用いた実ファイル生成・走査・キャッシュ整合性検証。
  - 大文字拡張子（`.EXE`, `.BAT`）の認識検証。

### 2.3 検索テスト (`src/search.rs` & `tests/search_integration.rs`)
- **単体テスト**:
  - 前方一致 vs 部分一致のスコア優先順位。
  - 電卓結果が存在する場合の最上位（index 0）固定配置。
  - 空クエリ時および最大件数制限（`max_results`）。
- **統合テスト**:
  - 大文字・小文字不問（`vscode` / `VSCODE` / `VsCoDe`）の一致検証。
  - ショートカットと電卓結果の複合シナリオ検証。

## 3. テスト実行 & 品質検証手順

```powershell
# 1. 全テストの実行（単体テスト + 統合テスト）
cargo test --all-targets

# 2. ドキュメンテーションテストの実行
cargo test --doc

# 3. 静的解析（リント）の実行（警告0件必須）
cargo clippy --all-targets -- -D warnings

# 4. フォーマット検証
cargo fmt --check
```
