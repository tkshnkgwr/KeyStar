# KeyStar: 手動動作確認（受入テスト）チェックリスト (MANUAL_TEST_GUIDE)

本書は、`KeyStar` の各リリース前や大型機能追加時に、人間（テスター／開発者）が実際に Windows 環境上で操作し、名作「CraftLaunch 2」の極小・爆速・キーボード特化の操作感を五感で検証するための**手動動作確認チェックリスト**です。

---

## 🚀 準備と起動手順

```powershell
# 1. リリースバイナリのビルド
cargo build --release

# 2. 起動（PowerShell またはエクスプローラーから直接起動）
.\target\release\KeyStar.exe
```
