# KeyStar: GUI設計方針 & UI/UX仕様 (GUI_DESIGN)

## 1. デザイン哲学（CraftLaunch 2の佇まい）

```text
+-------------------------------------------------------+
| > [ ここに入力（1行の極小テキストボックス）         ] |
+-------------------------------------------------------+
| = 1,408 (四則演算の即時結果)                          |
| * Chrome.lnk                                          |
+-------------------------------------------------------+
```

名作「CraftLaunch 2」の最大の魅力は、**「画面を占有せず、邪魔にならず、呼び出した瞬間にキーボードの入力先としてそこにある」** という極小・1行の佇まいでした。
`KeyStar` は、現代の過剰に装飾されたUI（半透明ブラー、巨大な検索カード、リッチなサムネイル等）をあえて排し、**道具としての切れ味と視認性** を最優先します。

---

## 2. ウィンドウ構造 & 配置仕様

| 項目             | 設定値 / 仕様                                           |
| :--------------- | :------------------------------------------------------ |
| **ウィンドウ枠** | タイトルバーなし（Borderless / Frameless）              |
| **常時最前面**   | Always on Top（呼び出し時は他の全ウィンドウの上に表示） |
| **タスクバー**   | タスクバーに表示しない（システムトレイ常駐）            |
| **初期表示位置** | プライマリモニタの画面中央、または画面上部（設定可能）  |
| **サイズ**       | 幅: 450〜550px / 高さ（入力欄のみ）: 36〜42px           |
| **候補展開時**   | 下方向に最大 5〜10 行分（高さ約 150〜250px）動的拡張    |

---

## 3. UIコンポーネント構成

### 3.1 1行入力テキストボックス (`TextEdit`)
- プレースホルダー: `> ここに入力...`
- ウィンドウ表示と同時にテキストボックスへ自動フォーカス（キーストロークの取りこぼしゼロ）。
- 背景色: ダークグレー / チャコール（`#1e1e1e`）。
- 文字色: 高コントラスト白（`#ffffff`）。
- キャレット: 高速ブリンク。

### 3.2 候補ドロップダウンパネル (`Candidates Dropdown`)
- **表示トリガー**:
  - テキストボックスに 1 文字以上入力されている場合、または `Down` / `Tab` 押下時に展開。
  - 入力が空、または合致する候補がゼロの場合は非表示（高さは入力欄のみに縮小）。
- **候補行の視覚表現**:
  - **電卓結果行**:
    - 最上部に緑またはシアン系のアクセントカラー（例: `= 1,408`）。
  - **ショートカット候補行**:
    - アイコンまたはファイル名＋拡張子（例: `Chrome (.lnk)`）。
  - **選択状態（アクティブ行）**:
    - 反転ハイライト（アクセントブルー `#264f78` 等）で明示。

## 4. キーボードインタラクション設計

| キー入力            | アクション内容                                                                                                                        |
| :------------------ | :------------------------------------------------------------------------------------------------------------------------------------ |
| `Alt + Space`       | ランチャーの表示 / 非表示トグル（グローバルホットキー）                                                                               |
| `Enter`             | **選択アイテムの確定実行**: <br>・電卓結果選択時: クリップボードへコピーし即非表示<br>・ショートカット選択時: `open` で起動し即非表示 |
| `Esc`               | 何もせず即座にウィンドウを非表示（非アクティブ化）                                                                                    |
| `Tab` / `Shift+Tab` | 候補リスト内の次 / 前の項目を選択                                                                                                     |
| `Ctrl+n` / `Ctrl+p` | Vim風の候補移動（下 / 上）                                                                                                            |
| `Down` / `Up`       | 矢印キーによる候補移動                                                                                                                |

## 5. `eframe` / `egui` による実装方針

- **イベントループ**:
  - `eframe::NativeOptions` で `decorated: false`, `always_on_top: true`, `transparent: false` を設定。
  - アプリケーション非アクティブ時（または Esc 押下時）はウィンドウを最小化または `set_visible(false)` で非表示化。
- **入力フォーカスの強制**:
  - ウィンドウ表示シグナル受信時に `response.request_focus()` を呼び出し、OSのアクティブ化遅延による入力漏れを防止。
